# 帧 A / 帧 B：目标描述与差距记录

## 帧 A —— 日落 17:45（产品门面）

**场景设定**：
- 太阳高度角低（接近地平线，elevation ∈ (0, π/12)）
- 太阳色温 2200K 暖金，天光 9000K 冷侧
- 人工补光 2700K @ 25%（弱）
- toneMappingExposure 0.85–1.05
- Bloom strength 0.55 / radius 0.70 / threshold 0.85

**必须看到的**：
1. 太阳圆盘经玻璃折射透入室内（transmission 1.0 + ior 1.5），不是死白板
2. 体积光柱只由太阳穿过洞口产生（人工灯不产光柱）
3. 木地板有板缝高光带（roughness 0.4 + roughnessMap + clearcoat 0.15）
4. 墙面有微 normal 起伏（乳胶漆质感，不死平）
5. 冷暖对比：阳光侧暖金、天光侧冷蓝，画面里有明确梯度
6. 阴影清晰（太阳 2048² PCFSoft，bias -0.0005）

**禁止出现的**：
- 纯人工光白盒子（无太阳主光）
- 绿色/黄色活动区线框常显
- JSON 导入导出 / lux 数字 / XYZ 坐标在主画面
- 白墙一起 Bloom 溢出（threshold 太低）

## 帧 B —— 夜间 21:00（纯人工光）

**场景设定**：
- 太阳在地平线下（sunLight 归零）
- 人工补光 2200K @ 15% + 屏幕光（弱氛围）
- toneMappingExposure 0.65
- Bloom strength 0.45 / threshold 0.90

**必须看到的**：
1. 灯体 emissiveIntensity > 1，触发 Bloom（但不糊整墙）
2. 人工灯不产生体积光柱（只有太阳产光柱）
3. 重点灯（餐桌吊灯）开 shadow 1024，其余全关
4. 家具底部有假接触阴影贴片（径向渐变 alpha）
5. 整体暗调，靠灯具 + 屏幕光撑气氛，不是死黑

**禁止出现的**：
- 太阳还在画面里（夜晚太阳应归零）
- 人工灯产体积光柱（廉价感根因）
- 调试控件泄漏
