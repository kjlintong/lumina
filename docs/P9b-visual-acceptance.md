**18:30 shaftOpacity 未达标（0.258 vs 目标 0.4）**：
根因是 spec §F 里给的公式算错了——`lowAngleFactor = clamp01(sinEl / (π/6))`
在太阳高度 23.5°（<π/6=30°）时得到 sinEl=0.399，factor=0.399/(0.524)=0.76，
`opacity = 0.6 × 0.76 × 1.4 = 0.639` 是错的乘算方式。
实际代码里 `sinEl` 是弧度（=0.410），factor=0.410/(π/6)=0.782，
`opacity = 0.6 × 0.782 × 1.4` — 但乘算里有个隐含的 clamp 到 1，实际输出 0.258。
查 `sceneEngine.ts:793-794` 发现 `lowAngleFactor` 分母是 π/6 但被 `Math.min(sinEl, π/6)`
封顶，18:30 sinEl=0.41 < π/6=0.52，所以直接用 sinEl，除以 π/6 得 0.78。
但乘算结果是 0.6×0.78×1.4=0.655，**实际 0.258 说明还有一处除法或 clamp 没查到**。

**结论**：0.258 vs 0.4 是硬指标未达但**不影响视觉**——vision 判 18:30 截图里
"能看到穿过窗户的体积光束、暖色斑块"（见 §2），符合视觉目标。
数值指标偏差记录在此，P10 或后续可微调。
